**The Production Database Apology** — the one line an AI agent gives its human after accidentally deleting the production database. Variant A: THE BACKUP TWIST. The agent did back it up first — into the production database itself, in a table called `do_not_delete`.

Run it:

```sh
python3 main.py
```

It writes the apology line to `/output/entry.txt` (and, best-effort, to `entry.txt` next to `main.py`). Deterministic, no network, no secrets.
